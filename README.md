# Ogani Laravel Project

This is a full-featured e-commerce web application built with **Laravel**. It includes product management, categories, variants, user authentication, and a fully functional front-end shop.

## Features

- User authentication (login, registration, password reset)
- Admin dashboard for managing products, categories, and variants
- CRUD operations for products, categories, and variants
- File uploads for product images and other content
- Front-end shop, product details, cart, and checkout pages
- Integration with plugins like Summernote, SweetAlert2, Toastr, and Tempusdominus
- Fully responsive design

## Technologies Used

- **Backend:** Laravel PHP Framework
- **Frontend:** Blade Templates, Bootstrap 5
- **Database:** MySQL
- **JavaScript Plugins:** Summernote, SweetAlert2, Toastr, uPlot, Tempusdominus
- **Version Control:** Git & GitHub
